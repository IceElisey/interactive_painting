# Проект "Интерактивные картины"

## Описание проекта
Данный проект был реализован для сайта про извесного художника Ивана Шишкина со сменными картинами.

## Цели проекта 
Разработать интерактивный сайт с картинками.

## Используемые технологии
- HTML для вёрстки страницы
- CSS для настройки стилей

## Установка зависимостей 
Загрузите репозиторий. Для этого скачайте проект и разархивируйте его.

## Пример запуска
Чтобы увидеть результат кода, откройте папку с проектом, дважды нажмите на файл index.html. Результат появится в браузере. Вы должны увидеть это:
